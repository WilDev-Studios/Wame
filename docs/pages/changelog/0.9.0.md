# Version 0.9.0

Released `UNRELEASED`

## Breaking Changes

## Additions

- New `Engine`-based plugin events:
    1. `BackgroundChangedEvent`
    2. `GameLoopStatusChangedEvent`
    3. `GameLoopSteppedEvent`
    4. `MouseLockChangedEvent`
    5. `MouseVisibilityChangedEvent`
    6. `PipelineChangedEvent`
    7. `SceneRegisteredEvent`
    8. `SceneSwitchedEvent`
    9. `UpdateIntervalChangedEvent`
    10. `Settings`-related:
        - `SettingsAntialiasingChangedEvent`
        - `SettingsMaxFPSChangedEvent`
        - `SettingsVSyncChangedEvent`

## Fixes

- Plugin name underscores are replaced with periods in logs, i.e. `MyCompany_Plugin` <=> `MyCompany.Plugin`.
- Plugin names in logs are now right-aligned to make reading easier.
- `Engine`.`set_pipeline` still restricted the `OpenGL` pipeline from being used.
